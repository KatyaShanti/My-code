## Числа с точками
Во всех таблицах числа показываются так: 60.750 (точка между тысячами, без копеек, без значка валюты). В Notion это делается парами колонок: числовая колонка с пометкой «⚙» (по ней считаются суммы, в видах она скрыта) и текстовая формула без пометки. Формула для числа X (подставь вместо X нужное выражение, например prop("Сумма ⚙")):
let(n, round(abs(X)), if(n >= 1000000, format(floor(n / 1000000)) + "." + substring(format(1000 + mod(floor(n / 1000), 1000)), 1) + "." + substring(format(1000 + mod(n, 1000)), 1), if(n >= 1000, format(floor(n / 1000)) + "." + substring(format(1000 + mod(n, 1000)), 1), format(n))))
Важно: не используй регулярные выражения и replaceAll с "$1" (Notion выдаёт ошибку). Сначала создавай базу только с обычными колонками, а формулы добавляй отдельным шагом.

Полоска прогресса (p от 0 до 1):
repeat("🟩", floor(p * 10)) + repeat("⬜", 10 - floor(p * 10)) + " " + format(floor(p * 100)) + "%"

## База «👛 Кошельки»
