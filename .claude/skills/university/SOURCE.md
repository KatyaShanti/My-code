# Источник

Адаптировано из https://github.com/yasikvlad/university-template (MIT license,
см. `LICENSE` в этой папке) под запуск внутри Claude Code сессии — без
терминала и без TTY-интервью. Оригинальный шаблон разворачивается через
`bootstrap.sh` + `interview.py` (нужен настоящий терминал); этот скилл делает
то же самое разговором в чате.
