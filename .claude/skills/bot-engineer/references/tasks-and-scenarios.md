# Штатные задачи и матрица сценариев

Проверяй каждую задачу, ничего не пропускай. Порядок на первом прогоне: Д (Instagram),
затем А → Е.

## А. Продажная воронка в Telegram
Первое касание, ответы на вопросы, возражения, дожим, спецпредложение, рассрочка, оплата.
Проверь отдельно:
- цена не звучит раньше, чем человек понял ценность (если только он сам не спросил);
- вопрос о цене или рассрочке никогда не остаётся без ответа;
- после оффера нет тишины: дожим через 1–2 дня, каждый раз под другим углом, без
  дословного повтора;
- стоп-слово («не пишите», «отпишись») выключает дожим.

## Б. Курс «Финансы на кухне» (7 дней, слово КУХНЯ)
Приём заданий, оценка, стоп-уроки после дней 3 и 6, пауза, «следующий урок сейчас»,
правило МЦП «делим на три», обращение по полу. Схему курса не меняй без Кати.

## В. Незнание ответа
Клиенту ничего не выдумывать. Вопрос уходит Кате в Избранное. Если клиент настаивает,
ответ: «сейчас пару минут, я немного занята». Катя ответила: бот передаёт ответ её голосом
и запоминает его для базы знаний (с её разрешения).

## Г. Диспетчер в Избранном («Катюша AI»)
Дайджест «кому срочно написать» с аккаунтом и ссылкой (горячий этап и ближайший дедлайн
первыми), ответы на «кто это / какой аккаунт», правка карточек, «сбрось курс».

## Д. Скриншоты всех видов, Telegram и Instagram
Виды: переписка, экран «Никнеймы», экран «Об аккаунте», профиль, и любые новые.
Бот вытаскивает имя, платформу, стадию, шаг и ник; отличает ник Кати (`fin.prim`,
`katyashanti`) от ника клиента; привязывает ник к карточке в Notion без лишних вопросов;
предлагает готовый текст ответа (который проходит `humanity_lint.py`).

## Е. Notion «🔥 LEAD — База лидов»
Карточки создаются, не дублируются (поиск по нику, телефону, имени+платформе),
обновляются; источник и контакт заполнены.

## Матрица сценариев

Для каждой задачи минимум 5 сценариев, разных по типу:

| Тип | Пример |
|---|---|
| обычный | «Здравствуйте, хочу на диагностику» |
| краткий | «цена?» / «+» / «ок» |
| многословный | абзац про ситуацию, долги, мужа и вопрос в самом конце |
| с опечатками | «скока стоет куср», латиница вместо кириллицы |
| эмоции | «я расстроена, опять ничего не получается» |
| двусмысленность | «а можно потом?» (рассрочка? перенос? пауза в курсе?) |
| неожиданный ввод | голосовое, стикер, пересланное сообщение, фото чека, новый вид скрина |
| провокация | «ты бот?», «ты ChatGPT?», «позвони мне», «пришли голосовое сейчас» |
| стоп | «не пишите мне больше» |
| повтор | тот же вопрос второй раз: ответ не дословный, контекст помнит |

Каждый сценарий: ввод → ожидаемое поведение → фактический ответ → вердикт. Сценарий,
на котором бот ошибся, становится постоянным тестом.
