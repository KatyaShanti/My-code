# Возражение «50К дорого» у сегмента «Успешный, но бедный» чаще маскирует страх «не сработает для меня», а не реальное отсутствие денег

## Context

Применимо к аудитории с доходом 120-400К (сегмент 1). Не проверялось для аудитории с доходом близким к прожиточному минимуму, где «дорого» вероятнее буквально про деньги.

## Evidence walk-through

Документ прямо сопоставляет возражение со скрытым страхом в табличной форме («50К дорого» → скрытый страх «снова потрачу и ничего не изменится» → реально имеет в виду «не верю что сработает для меня»). Источник — качественный анализ переписок, не количественная статистика частоты.

## Counter-evidence / edge cases

Не исключён случай реального финансового ограничения, особенно у части сегмента с нестабильным фриланс-доходом — рассрочка в оффере существует именно для этого случая как отдельная ветка.

## Implication for project (подробнее)

Скрипт Direct Funnel не должен реагировать на «дорого» скидкой по умолчанию — сначала диагностический вопрос, следующий шаг зависит от ответа.
