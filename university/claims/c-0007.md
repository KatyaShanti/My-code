# Кейсы с точными цифрами точка А/точка Б конвертируют сильнее, чем размытые формулировки результата

## Context

Общее правило для всего продающего контента, не тестировалось отдельно на каждом канале (Reels vs пост vs личная переписка).

## Evidence walk-through

Правило заявлено как общее в ДНК проекта («Общие правила»: «Кейсы всегда в цифрах») и подкрепляется тем, что все собранные реальные кейсы содержат точные суммы — но нет прямого A/B сравнения цифра-vs-размыто на одной и той же аудитории.

## Counter-evidence / edge cases

Возможен эффект «слишком много цифр» для части аудитории (когнитивная перегрузка) — не проверялось, держим как открытый вопрос.

## Implication for project (подробнее)

Хранить дисциплину точных цифр как чек-лист качества для любого нового Reels/поста с кейсом.
