# Скидка 49К вместо 55К «только на созвоне» — рабочий фрейм честной срочности при отсутствии фиксированной даты завершения набора

## Context

Применимо только к моменту живого созвона/диагностики, не к письменному контенту (Reels/сторис), где вместо цены используется квота 4-5 клиентов в месяц как срочность.

## Evidence walk-through

Документ рекомендует этот фрейм как «конверсионный триггер на диагностике», но не приводит измерения before/after — это рекомендация методологии, не результат эксперимента.

## Counter-evidence / edge cases

Риск: если клиент узнает (от знакомых, из комментариев), что скидка звучит на каждом звонке — эффект срочности исчезает, превращается в дефолтную цену. Не отслеживалось в собранных материалах.

## Implication for project (подробнее)

Использовать формулировку «сегодня на звонке» последовательно во всех сценариях созвона, не варьировать цену случайным образом между клиентами без причины.
