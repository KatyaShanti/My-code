# 4-недельная стратегия прогрева соответствует смещению распределения аудитории продукта по уровням Ханта

## Context

Стратегия применима к аудитории уже подписанной/наблюдающей за аккаунтом на протяжении месяца — не годится для холодного разового посетителя, увидевшего один Reels.

## Evidence walk-through

Логика документа последовательна (каждая неделя таргетирует конкретные уровни и смыслы №), но нет отдельного измерения, что аудитория реально смещается по уровням именно за 4 недели, а не за другой срок — отсюда confidence L, не M.

## Counter-evidence / edge cases

3-дневный мини-прогрев этой сессии — прямой контрпример альтернативного темпа: та же логика (пробуждение→доказательства→оффер) сжата в 3 дня, а не растянута на 4 недели, без данных о том, какой темп реально лучше конвертирует.

## Implication for project (подробнее)

Не считать 4 недели догмой — при построении будущих прогревов тестировать разные длительности цикла и измерять фактическое смещение аудитории по уровням через ответы на Вердикт-диагностику.
