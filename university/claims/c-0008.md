# Наличие персонажей, сюжета и развязки во времени внутри таблицы-сравнения — определяющий фактор её конверсии, не сам факт таблицы

## Context

Основано на сравнении 2 реальных роликов схожей длины (6-7 сек) одного аккаунта — не кросс-аккаунтное исследование, возможны эффекты, специфичные для @fin.prim (аудитория, алгоритмическая история аккаунта).

## Evidence walk-through

Прямое сопоставление трёх измерений с контролем по длительности: 0,085% (микро-хук, без таблицы вообще), 0,078% (таблица+сюжет), 0,027% (таблица без сюжета) — таблица-с-сюжетом почти равна безтабличному хуку и втрое обгоняет таблицу-без-сюжета, что изолирует переменную «сюжет» от переменной «таблица».

## Counter-evidence / edge cases

N=2 для табличных форматов — статистически тонкий лёд для вывода такой силы (confidence H может быть завышен относительно объёма данных; при добавлении новых замеров пересмотреть).

## Implication for project (подробнее)

Reels №2 этой сессии («Куда уходят твои 300К: ДО и ПОСЛЕ») сознательно построен с элементом драматургии (два состояния во времени), а не как плоский список процентов — прямое применение этого claim.
