# Короткие вирусные форматы и длинные личные истории — взаимодополняющие инструменты воронки, не конкуренты

## Context

Вывод по 4 роликам одного аккаунта за ограниченный период — не проверено на устойчивость во времени (сезонность, усталость аудитории от одного типа контента).

## Evidence walk-through

Явный trade-off в данных: реел с максимальным охватом (1,45М) даёт среднюю конверсию (0,078%), реел с минимальным охватом (5,4К) даёт максимальную конверсию (0,256%) — паттерн согласуется с обобщённым правилом «reach vs quality», но выборка мала для более сильного confidence.

## Counter-evidence / edge cases

Возможна альтернативная интерпретация: личная история набрала мало просмотров просто потому что вышла позже/в другое время/без промо, а не из-за формата как такового — причинность не изолирована.

## Implication for project (подробнее)

В календарном плане прогрева сознательно закладывать долю личных историй, не оптимизировать состав контента только под охват.
