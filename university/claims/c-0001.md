# Аудитория сегмента «Успешный, но бедный» реагирует на триггер узнавания «снова ноль к зарплате» сильнее, чем на прямую формулировку продукта

## Context

Справедливо для холодной/тёплой Instagram-аудитории на верхних уровнях воронки (Хант 0-2). На уровне 4-5 (сравнивает продукты, готов покупать) прямая формулировка ценности продукта уже уместнее.

## Evidence walk-through

ДНК клиента фиксирует «точку невозврата» сегмента через узнавание себя в чужом кейсе/формулировке боли («это же я»), а не через описание методики. Само по себе это качественное наблюдение автора документа, не A/B-тест.

## Counter-evidence / edge cases

Возможно смешение причины и следствия: узнавание боли может работать не потому что это «лучший хук», а потому что весь верхнеуровневый контент в принципе так устроен (нет контрольной группы с продуктовым хуком на сопоставимой аудитории).

## Implication for project (подробнее)

Держать структуру «боль его словами → доказательство → продукт» как стандарт для Reels/сторис верхней воронки; не тестировали обратный порядок в этой сессии.
