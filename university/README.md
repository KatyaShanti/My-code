# Университет — Финансовое наставничество Кати Шанти

База знаний по методологии [university-template](https://github.com/yasikvlad/university-template): source → conspect → atomic notes → claims → synthesis → verdict.

**Миссия:** собрать проверяемую базу знаний, достаточную чтобы обоснованно строить контент- и воронка-стратегию финансового наставничества Кати Шанти — от ДНК аудитории и лестницы Ханта до реальных метрик Reels и механики direct-продаж — чтобы каждое решение по контенту и воронке опиралось на факты (`claim`), привязанные к первоисточнику, а не на догадки.

## Как этим пользоваться

- Нужен ответ "что у нас известно про X" → смотри `syntheses/syn-<topic>.md`
- Нужен конкретный проверяемый факт с обоснованием → `claims/c-NNNN.md`
- Нужна одна атомарная мысль → `notes/n-<slug>.md`
- Появился новый источник (ссылка, скрин, документ) → прогнать через пайплайн в `METHODOLOGY.md` §4
- Два источника противоречат друг другу → `contradictions/`, не игнорировать молча
- Полный индекс всего собранного → `INDEX.md`

Полная методология — `METHODOLOGY.md`. Дерево тем — `TAXONOMY.md`.

## Особенность этого проекта

Первичные источники — не статьи/whitepaper'ы, а **внутренние бизнес-документы Кати в Notion** (ДНК клиента, продуктовая линейка, реальная статистика Instagram Reels) плюс материалы, наработанные в диалоге с Claude (анализ форматов, скрипт продаж, финальные тексты). Все они размечены как seed-источники в `METHODOLOGY.md` §1.1 — обрабатываются как первичные (relevance=5), конспекты не переписываются заново (Notion-страница = уже готовый conspect), но атомарные заметки и claim'ы из них извлечены.
