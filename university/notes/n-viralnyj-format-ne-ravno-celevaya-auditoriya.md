# Виральный охват не равнозначен целевой аудитории — широкие форматы приводят много случайных зрителей с низким намерением подписаться

Обобщение по 4 замерам: чем шире и провокационнее хук (микро-хук, таблица-сравнение), тем больше в составе зрителей случайных людей, которые смотрят из любопытства, а не из совпадения с болью аудитории — отсюда более низкая, хотя и не катастрофическая, конверсия в подписку по сравнению с узкой, но целевой личной историей. Confidence M, а не H — вывод построен всего на 4 наблюдениях без контроля состава аудитории напрямую (только косвенно через % неподписчиков в одном из замеров, 99,7%).
