## TL;DR

Полный скрипт переписки от получения слова «ВЕРДИКТ» до закрытия на оплату: сбор 4 цифр → 1-2 SPIN-вопроса для диагностики уровня осознанности → голосовой разбор → приглашение на созвон → структура созвона (5 конвертов → 30К скрытых денег → оффер 49-55К) → таблица возражений → закрытие → follow-up тайминги.

## Thesis

Главное золотое правило — не объяснять продукт тому, кто ещё не осознал проблему; сначала довести человека до «да, у меня есть проблема» через SPIN-вопрос, и только потом переходить к решению.

## Key points

- Этап 0: тёплый первый ответ с явным списком (не стеной текста) — какие 4 цифры прислать
- Этап 1: диагностика уровня по 1-2 вопросам (Situation/Problem из SPIN) до отправки голосового разбора
- Этап 2: голосовой + альтернативный вопрос по времени созвона (не «хотите ли созвон»)
- Этап 3 (структура созвона): 5 конвертов на цифрах клиента → 30К скрытых денег как быстрый wow-эффект → оффер только после ценности (Ценность→Стоимость→Вопрос)
- Таблица возражений «дорого»/«подумаю»/«сама разберусь» с готовыми ответами через выяснение скрытого страха, не через спор
- Закрытие: итог без вопроса → альтернативный вопрос на способ оплаты → способ → без болтовни к делу
- Follow-up тайминги по ситуации (молчание после голосового — через 1 день, «подумаю» — через 2-3 дня и т.д.)

## Methods / evidence

Синтез методологии продаж (sales-assistant, реальные кейсы Софии Добрыниной из другой практики) + продуктовых данных Кати (src 1-3) — это конструирование скрипта, не наблюдение за реальными диалогами по этому конкретному скрипту. Требует проверки на практике (см. открытый вопрос в syn-funnel-mechanics.md).
